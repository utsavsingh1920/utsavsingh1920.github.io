A final-year B.Sc. IT academic project focused on **resume analysis, skill identification, candidate scoring, and feedback** using Python, Streamlit, and SQLite.

The application analyzes uploaded resumes to identify relevant skills and provides useful recommendations for improving the candidate profile.

### Key Features

- Resume PDF upload
- Resume text extraction
- Skill and keyword identification
- Candidate resume scoring
- Resume improvement suggestions
- Course recommendations
- Feedback functionality
- Admin functionality
- SQLite data storage

### Technologies

`Python` `Streamlit` `SQLite` `NLP`
